\# Glossary



\## Broker



Middleware responsible for receiving and delivering messages.



\## Queue



Messaging structure where each message is consumed once.



\## Topic



Messaging structure supporting publish/subscribe communication.



\## Producer



Application that sends messages.



\## Consumer



Application that receives messages.



\## JMS



Java Message Service.



\## ESB



Enterprise Service Bus.



\## Event



Something that happened within a system.



\## Throughput



Amount of work processed over time.



\## Latency



Time required to complete an operation.
