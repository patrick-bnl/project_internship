\# Apache Kafka



\## Overview



Apache Kafka is a distributed event streaming platform.



\## Core Components



\### Producer



Publishes records.



\### Topic



Logical stream of events.



\### Partition



Unit of parallelism.



\### Broker



Kafka server.



\### Consumer Group



Group of consumers sharing workload.



\## Strengths



\- High throughput

\- Large ecosystem

\- Strong community

\- Industry adoption



\## Study Topics



\- Topic design

\- Partitioning

\- Replication

\- Consumer groups

\- Exactly-once semantics
