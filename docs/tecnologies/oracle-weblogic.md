\# Oracle WebLogic



\## Overview



Oracle WebLogic is an enterprise Java application server.



\## Features



\- Java EE support

\- JMS messaging

\- Clustering

\- Security

\- Transaction management



\## Typical Uses



\- Enterprise applications

\- Service hosting

\- Messaging infrastructures



\## Areas to Investigate
