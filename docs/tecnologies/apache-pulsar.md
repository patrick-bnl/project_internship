\# Apache Pulsar



\## Overview



Apache Pulsar is a distributed messaging and event streaming platform.



\## Core Components



\### Producer



Publishes messages.



\### Consumer



Consumes messages.



\### Broker



Handles communication.



\### Apache BookKeeper



Stores message data.



\## Strengths



\- Multi-tenancy

\- Geo-replication

\- Tiered storage

\- Flexible subscription models

\- BookKeeper
