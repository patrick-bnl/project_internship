\# Distributed Systems



\## Definition



A distributed system is a collection of independent computers that appears to users as a single coherent system.



\## Characteristics



\- Multiple nodes

\- Network communication

\- Shared objectives

\- Independent failures



\## Challenges



\### Latency



Communication takes time.



\### Partial Failure



One component may fail while others continue to work.



\### Scalability



The system must support growth.



\### Consistency



Data must remain reliable across nodes.



\## Key Concepts



\### Throughput



Number of operations processed per unit of time.



\### Latency



Time required for an operation to complete.



\### Availability



Percentage of time the system remains operational.



\### Fault Tolerance



Ability to continue operating despite failures.



\## Relevance to Messaging Systems



Kafka, Pulsar and WebLogic are designed to support communication between distributed systems.
