\# Java Message Service (JMS)



\## Definition



JMS is a Java specification for messaging between applications.



\## Main Concepts



\### Queue



Point-to-point communication.



\### Topic



Publish/Subscribe communication.



\### Producer



Sends messages.



\### Consumer



Receives messages.



\### Message



Data being exchanged.



\## JMS Providers



\- Oracle WebLogic

\- ActiveMQ

\- IBM MQ

\- OpenMQ



\## Importance



Many enterprise applications and legacy integrations rely heavily on JMS.
